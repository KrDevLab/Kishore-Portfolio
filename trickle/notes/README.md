# Kishore Ravi - Portfolio Project

This is a modern, premium, fully responsive personal portfolio website for Kishore Ravi (UI/UX Designer & Frontend Developer).

## Technology Stack
- React 18
- Tailwind CSS (via CDN with custom config)
- Lucide Icons

## Features Included
- Dark modern glassmorphism aesthetic
- Smooth scroll reveals using Intersection Observer API
- Pure CSS floating animations and blob backgrounds
- Responsive layout (Mobile, Tablet, Desktop)
- Sections: Hero, About (Bento Grid), Skills, Projects (with tabs), Services, Experience Timeline, Why Work With Me, Contact Form UI, Footer.
- Additional Pages: Hire Me, Terms & Conditions, Payment Gateway simulation.

## Notes & Rules
- This website relies strictly on frontend code using HTML, CSS, and JS (via Babel for JSX).
- No build steps required.
